## 我在 Linux 课上学到了什么

1. **命令行思维**：Linux 里"一切皆文件"，绝大多数操作都可以用一条命令完成，`man` 和 `--help` 是最好的老师。
2. **权限与用户**：`rwx` 三个权限位、`chmod`/`chown`、用户与用户组的关系，是理解 Linux 安全模型的基础。
3. **Shell 脚本**：把重复的操作写成脚本，变量、判断、循环、函数组合起来就能完成相当复杂的自动化任务。
4. **文本处理**：`grep` 找行、`sed` 改行、`awk` 按列处理，三者配合管道几乎可以替代简单的小工具。
5. **工程化**：`gcc` 编译、`make` 构建、`git` 版本管理，以及用 GitHub Actions 自动部署静态站点。
